# 🏛️ Multi-School Stock Analyzer — محلل الأسهم متعدد المدارس

مؤشر احترافي لمنصة **TradingView** مكتوب بلغة **Pine Script v6**، يجمع أهم مدارس
التحليل الفني في مؤشر واحد منظّم، ويرسم على الشارت بشكل احترافي، مع **لوحة معلومات
(Dashboard)** تعطيك قراراً مجمّعاً (شراء/بيع/حياد) بناءً على تصويت كل المدارس.

> ⚠️ **تنبيه:** هذا المؤشر أداة مساعدة للقرار وليس توصية مالية. اختبره على حساب
> تجريبي وعلى بياناتك التاريخية قبل أي استخدام حقيقي. إدارة المخاطر مسؤوليتك.

## 🧠 مدارس التحليل المدمجة

| # | المدرسة | الأدوات | ما يرسمه على الشارت |
|---|---------|---------|----------------------|
| 1 | **الاتجاه** Trend | EMA 20/50/200 + شريط تعبئة | متوسطات ملوّنة + تعبئة قوة الاتجاه |
| 2 | **الزخم** Momentum | RSI + MACD + Stochastic | مثلثات تشبع شرائي/بيعي |
| 3 | **التقلب** Volatility | Bollinger Bands + ATR | قناة بولينجر مع تعبئة |
| 4 | **الدعم/المقاومة** S/R | Pivot High/Low تلقائي | خطوط أفقية متجددة |
| 5 | **فيبوناتشي** Fibonacci | ارتداد آلي من آخر سوينج | مستويات 0–100% مع تسميات |
| 6 | **إيشيموكو** Ichimoku | Tenkan/Kijun/Cloud | السحابة الكاملة (اختياري) |
| 7 | **الحجم** Volume | انفجار الحجم + OBV | دوائر على شموع الحجم العالي |
| 8 | **نماذج الشموع** Candles | ابتلاع/مطرقة/شهاب/دوجي | تسميات على الشموع |
| 9 | **هيكل السوق** SMC | Break of Structure (BOS) | تسميات BOS▲ / BOS▼ |
| 10 | **القرار المجمّع** | تصويت مرجّح لكل المدارس | لوحة معلومات + إشارات شراء/بيع |

---

## ⚙️ كيف يحسب القرار النهائي؟

كل مدرسة تعطي إشارة: **صاعد (+1)** / **هابط (−1)** / **حياد (0)**، ثم تُرجّح:

```
النتيجة = الاتجاه×2 + الزخم×1.5 + التقلب + إيشيموكو + الحجم + الشموع + هيكل السوق×1.5
النسبة٪ = النتيجة ÷ أقصى نتيجة ممكنة × 100
```

| النسبة | القرار |
|--------|--------|
| ≥ 50%  | شراء قوي 🟢 |
| ≥ 20%  | شراء 🟢 |
| بين −20% و +20% | حياد ⚪ |
| ≤ −20% | بيع 🔴 |
| ≤ −50% | بيع قوي 🔴 |

الاتجاه وهيكل السوق لهما وزن أعلى لأنهما الأكثر موثوقية في تحديد السياق العام.

## 🚀 طريقة التركيب على TradingView

1. افتح [TradingView](https://www.tradingview.com) → افتح شارت أي سهم.
2. من الأسفل افتح **Pine Editor** (محرر باين).
3. احذف المحتوى الافتراضي والصق كامل محتوى ملف `MultiSchoolAnalyzer.pine`.
4. اضغط **Save** ثم **Add to chart** (أضِف إلى الشارت).
5. اضبط الإعدادات من أيقونة ⚙️ بجانب اسم المؤشر — كل مدرسة لها مجموعة منفصلة
   ويمكن تفعيلها/تعطيلها بشكل مستقل.

### 🔔 تفعيل التنبيهات
من زر **Alert** اختر المؤشر، وستجد الشروط الجاهزة:
- إشارة شراء مجمّعة / إشارة بيع مجمّعة
- كسر هيكل صاعد / هابط (BOS)

## 🎛️ أهم الإعدادات

- **إظهار لوحة المعلومات** وموضعها (4 زوايا) + ثيم داكن/فاتح.
- تفعيل/تعطيل أي مدرسة على حدة لتقليل الازدحام على الشارت.
- أطوال المتوسطات، إعدادات RSI/MACD/Stochastic، انحراف بولينجر،
  حساسية البيفوت، نطاق فيبوناتشي، إعدادات إيشيموكو، وعتبة انفجار الحجم.

### نصائح للاستخدام
- للأسهم على الفريم اليومي: الإعدادات الافتراضية مناسبة.
- لتداول السكالبينج: قلّل أطوال المتوسطات وحساسية البيفوت.
- لا تعتمد على إشارة واحدة — انتظر **توافق عدة مدارس** (النسبة ≥ 50%).
